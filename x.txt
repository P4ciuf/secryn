# Secryn v1.0.0 — First Stable Release

A secure, developer-focused secrets management platform. Store, encrypt, and
access API keys, tokens, and environment variables safely through a dashboard,
CLI, and REST API.

🌐 **Website**: https://secryn.xyz
📦 **Docker Hub**: (coming soon)
🐍 **PyPI**: `pip install secryn-cli`

---

## Core Platform

- **Fastify 5 REST API** with full OpenAPI 3.1.0 spec and Swagger UI at `/docs`
- **React 19 + Vite 8 + Tailwind CSS v4** dashboard with 48 shadcn/ui components
- **PostgreSQL 18 + Prisma 7 ORM** with prepared statements via `@prisma/adapter-pg`
- **Redis 7** session store with ioredis for brute-force rate limiting
- **Docker Compose** production setup with multi-stage Dockerfiles (Node API + Nginx SPA)
- **pnpm monorepo** with workspace packages (`@repo/shared`, CLI, SDKs)

## Security

- **AES-256-GCM** secret encryption — raw values never touch the database
- **bcrypt** password hashing + **httpOnly JWT cookies** (no localStorage tokens)
- **scrypt** key derivation (N=131,072) for encryption keys
- **TOTP-based MFA** with QR setup, 10 recovery codes, email backup codes
- **CORS explicit allowlist** + **Helmet** security headers
- **Rate limiting** on all sensitive endpoints
- **Brute-force protection** with Redis counters and timing-safe dummy hashes
- **Audit logging** for all security events (login, MFA, secret CRUD)
- **Anti-enumeration** on forgot-password, login, and registration endpoints
- **OWASP Top 10** security review completed
- **CVE-2026-39406** resolved (`@hono/node-server` middleware bypass)
- No host port mappings — services are internal-only in Docker network

## Authentication & Authorization

- Email/password registration and login
- MFA with TOTP (otplib) and QR code (qrcode)
- JWT sessions via httpOnly cookies + automatic token refresh on 401
- API key authentication via `api-key` header for programmatic access
- Fine-grained project permissions (ALL, CREATE_SECRETS, READ_SECRETS, UPDATE_SECRETS, DELETE_SECRETS, MANAGE_MEMBERS, CREATE_INVITES)
- Password reset flow with single-use email tokens

## Secret Management

- Create, read, update, delete encrypted secrets scoped by project
- Partial updates (name, value, notes independently)
- Export secrets as downloadable `.env` file
- Client-side search and filtering with case-insensitive name matching
- Visibility toggle (show/hide values) with clipboard copy

## Projects & Teams

- Project workspaces with member invitations (7-day expiry, email via Resend)
- Granular permission assignments per member (add/remove permissions)
- Project ownership transfer between members
- Self-removal prevention for project owners

## API Key Management

- Generate API keys with `sc_` prefix and AES-256-GCM encryption at rest
- Read/write permission scoping (read-only keys rejected on write endpoints)
- Edit API key name, active status, and permissions with diff-based add/remove
- 30-day expiry and immediate revocation support

## Developer Tools

### CLI (`sc`)
```bash
pip install secryn-cli
```
- Cookie-based authentication with MFA login flow
- Full CRUD for projects, secrets, and API keys
- `.env` export with file output
- JSON output mode for scripting
- Interactive prompts with confirmation for destructive operations
- Config persistence in `~/.config/secryn/`

### Python SDK (`secryn`)
```bash
pip install secryn
```
- `SecrynClient` wrapping `requests.Session`
- Namespaced proxy objects: `.auth`, `.mfa`, `.users`, `.api_keys`, `.projects`, `.secrets`
- `SecrynApiError` with structured error fields (code, status, message)
- 92-test pytest suite

### TypeScript SDK (`@secryn/sdk`)
```bash
npm install @secryn/sdk
```
- `SecrynClient` with native `fetch`
- Internal `CookieJar` for Node.js cookie persistence
- Namespaced proxy sub-objects
- Debug-gated logger

## CI/CD

- GitHub Actions: lint, typecheck, test on push/PR
- Docker image build workflow
- PyPI publish via OIDC Trusted Publishing (CLI)
- SDK publish workflows (PyPI + npm)

## What's Next (Roadmap)
- Secret versioning and rotation
- CI/CD native integrations (GitHub Actions, GitLab CI)
- Teams and organizations
- Webhook event system
- Terraform provider
